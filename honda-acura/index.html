01 — The brief

Same ad, a thousand
different signatures

Two brands. Six IAB sizes. Two animated creative concepts plus a static retargeting cut. And the hard part: every one of 1,012 dealerships — 784 Honda, 228 Acura — needed its own name stitched into the creative. The traditional answer is a production team and a few weeks. This was one person, one chair, and an AI production line.

A

Summer road trip

The hero concept — scenic drive-bys, an odometer that spells out the season, a fan of Acuras opening like a hand of cards.

B

Postcards & heat haze

Vacation postcards shuffling on a wood table; an MDX driving into a shimmering sunset rendered with a live SVG displacement filter.

RT

Retargeting

The follow-you-around cut — deliberately 100% static, logo and offer only, engineered to the same per-dealer pipeline.

02 — The dealer engine Live demo

One spreadsheet,
18,216 finished files

Nothing is typed into an ad by hand. Every dealership lives as one row in one CSV — the single source of truth. An AI-written, zero-dependency build script stamps each row into each master through three tokens, and writes a self-contained, trafficking-ready package per dealer. No engineering department — just a spec, a conversation, and code that ships. Change the spreadsheet, rebuild, done. Watch it work — this is live:

03 — The lineage

These ads aren't video.
They're code.

Not one frame on this page came out of After Effects. Every ad here is code-generated HTML5 — CSS and SVG animation written with AI, light enough to live in a banner slot. The playbook is what we carried over: years of automating After Effects taught us the template-plus-spreadsheet assembly line. AI let us rebuild it without a render farm.

04 — The craft

Every frame directed,
every line generated

Four master ads, built from the client's PSDs and storyboards. A human called every creative shot — the timing, the easing, the frame the client would feel. AI wrote the code: pure CSS and SVG animation, no video, no canvas, a few hundred kilobytes each. Expert code without the expert. These are the real ads, running live. Hit replay.

05 — The scale-out

Four masters became
thirty-six ads

Once the client approved the four 300×600 anchors, every other size was derived from them — five AI sessions building in parallel, each verifying its work against the client's storyboard before reporting done. An entire production department, running in one chair. Every tile below is a real render at true pixel size, each stamped with a different real dealership.

06 — The review loop

Storyboard in,
shipped pixels out

The client never reviewed screenshots — they reviewed a live web page: every ad running beside its storyboard frame, with a notes box under each unit. Notes saved straight to structured JSON, were applied as a batch — each fix verified against the comp before it counted — then archived. Twelve rounds, fully traceable, nothing lost in an email thread.

07 — The multiplier

One person.
A studio in a chair.

The taste, the storyboard reading, the call on every frame — human. Everything a studio would staff for, AI did: five agent sessions building sizes in parallel against a shared spec, a headless-browser harness freeze-framing every ad and comparing it to the client comp, client notes applied as verified batches. The animator, the production artist, the QA desk, the traffic department — one chair.

Parallel, not sequential

Thirty-two derivative sizes were built in one coordinated run by five AI sessions, each reading the same ground-truth spec — the document that encodes every hard-won client correction.

Proof over promises

No change shipped on "looks right." A headless browser froze every ad at key timestamps and the render was compared against the client's storyboard — every round, every unit.

Feedback as data

Client notes became structured JSON the moment they were typed. Batches were applied, verified, archived — twelve rounds of revisions with a complete audit trail.
