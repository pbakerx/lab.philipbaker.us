# Honda A (300×600) — what we changed

Plain-language summary of the creative revisions, for client review.

- **Headline is now vector artwork.** Converted the headline ("Wherever
  summer takes you, expert service gets you there.") from live text to an
  SVG graphic, so it stays razor-sharp at any screen size.
- **Removed embedded fonts.** With the headline as a graphic, the ad no
  longer ships or loads a custom font file.
- **New crisp logo.** Swapped the logo to a vector (SVG) version and removed
  its drop shadow for a cleaner, flat look.
- **Dealer copy is one consistent block.** "Visit the experts at [Dealer]"
  reads as a single unit and stays at **one fixed size for every dealer** —
  long dealer names wrap to another line instead of shrinking, so the type
  looks identical across the whole dealer list.

_The only live (dynamic) text in the ad is the dealer name and its intro
line. Everything else — headline, logo, the "BEACH" mileage graphic — is
now fixed artwork._
