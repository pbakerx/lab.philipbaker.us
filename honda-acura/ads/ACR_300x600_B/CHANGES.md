# Acura B (300×600) — what we changed

Plain-language summary of the creative revisions, for client review.

- **New heat-wave treatment.** Built from your vector line art, with a
  continuous horizontal "rising heat" ripple plus a vertical lift reveal so
  the lines appear to rise. Tuned the line thickness, transparency, and how
  high the effect sits in the sky.
- **New hero car with a "driving away" move.** The car recedes left-to-right
  while gently zooming out with a slight tilt; raised the car for better
  framing while keeping the frame fully filled.
- **Headline is now vector artwork.** Converted the headline ("Summer / Road
  Trips / Handled With / Precision.") from live text to SVG graphics — sharp
  at any size.
- **Removed embedded fonts — this ad now uses none at all.** The headline is
  a graphic and the dealer copy uses a standard system font.
- **New crisp logo.** Vector (SVG) version of the Acura mark.
- **Dealer copy is one consistent block** at **one fixed size for every
  dealer** — long names wrap instead of shrinking.

_The only live (dynamic) text in the ad is the dealer name and its intro
line. Everything else — headline, logo, heat-wave art — is now fixed
artwork._
