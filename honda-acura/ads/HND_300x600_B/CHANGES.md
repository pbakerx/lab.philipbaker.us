# Honda B (300×600) — what we changed

Plain-language summary of the creative revisions, for client review.

- **New static wood background.** Replaced the old panning wood image with
  the new static `WoodSandBg` deck, sized to fill the frame.
- **Headline is now vector artwork.** Converted the headline ("When summer
  calls, expert care delivers.") from live text to an SVG graphic — sharp
  at any size. Tuned its size and vertical position to match the comp.
- **Removed embedded fonts** for the headline (it's a graphic now).
- **New crisp logo.** Swapped the logo to a vector (SVG) version and removed
  its drop shadow for a clean, flat look.
- **Dealer copy matched to Honda A.** "Visit the experts at [Dealer]" now
  uses the same type as Honda A and reads as one consistent block at **one
  fixed size for every dealer** — long names wrap instead of shrinking.

_The only live (dynamic) text in the ad is the dealer name and its intro
line. Everything else — headline, logo — is now fixed artwork._
