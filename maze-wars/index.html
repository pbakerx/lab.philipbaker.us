Maze Wars+ — the 1986 Macintosh network maze shooter, playable online

A first-person maze drawn in one-bit dither. Move with F, turn with D and G, side-step with J and L, fire with K or Space, or use the arrow keys; Return opens the message box to chat with whoever else is online. Pick an appearance, find the teleporters and the lifts between the four mazes, and mind the robot.
